# 🏗️ Smart Task Architect

A production-ready Streamlit application for high-performance task management and orchestration.

## 🚀 Features
- **Task Deployment**: Quick-entry form with priority scaling.
- **Real-time Analytics**: Dashboard metrics for workload monitoring.
- **Data Persistence**: Local CSV-based storage to ensure data persistence across sessions.
- **Interactive Grid**: In-line data editing using Streamlit's `data_editor`.
- **Operations Layer**: Ability to delete and purge tasks efficiently.

## 🛠️ Tech Stack
- **Frontend**: Streamlit
- **Logic**: Python / Object-Oriented Design
- **Storage**: Pandas / CSV

## 🏃 How to Run
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Launch the application:
   ```bash
   streamlit run app.py
   ```
